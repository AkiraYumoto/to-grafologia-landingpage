# 🖋️ To.Grafología - Landing Page Profesional

Bienvenido al repositorio de la landing page de **To.Grafología**, una marca especializada en Grafología Científica. Este proyecto fue diseñado con un enfoque Mobile-First y estructurado mediante prompt engineering avanzado utilizando Google Stitch.

## 🎯 Objetivo del Proyecto
Crear una presencia digital de alta autoridad que atraiga a particulares, empresas y profesionales del ámbito judicial. El diseño busca un equilibrio perfecto entre el rigor científico y una estética sofisticada, minimalista y femenina.

## 🎨 Identidad Visual y UI/UX
El diseño se basa en una jerarquía visual clara y componentes modernos:
* **Colores Principales:** Lila (Lavanda) para acentos de marca y Verde Menta para llamadas a la acción (CTAs).
* **Fondo:** Blanco puro con texturas sutiles que evocan el papel de alta calidad.
* **Tipografía:** Combinación de fuentes Serif elegantes para los títulos (autoridad) y Sans-serif geométricas para el cuerpo de texto (legibilidad).
* **Estética:** Bordes redondeados (12px), sombras suaves y uso generoso de espacio en blanco (white space).

## 🏗️ Arquitectura de la Información
La landing page está dividida en 6 secciones estratégicas:
1.  **Hero Section:** Banner de alto impacto con propuesta de valor clara y CTA principal.
2.  **Sobre Mí:** Perfil profesional de Tatiana Olivera, Grafoanalista.
3.  **Servicios (Grid de 3 columnas):**
    * Particulares (Autoconocimiento)
    * Empresas e Instituciones (RRHH y Selección)
    * Ámbito Judicial y Clínico (Peritaje y Soporte)
4.  **Inversión:** Tarjetas de precios/presupuestos para cada tipo de servicio.
5.  **Blog / Recursos:** Diseño en formato carrusel (estilo Instagram) para mostrar artículos como *¿Por qué garabateamos?*.
6.  **Contacto:** Formulario *Lead Magnet* optimizado para conversiones.

## 🛠️ Stack y Herramientas
* **Desarrollo y Código:** Implementación técnica, despliegue y gestión del repositorio.
* **Diseño Generativo UI/UX:** Google Stitch (AI UI Generation).
* **Prompting:** Estructurado en formato JSON lógico para máxima precisión en la renderización de la IA.
* **Enfoque:** Diseño Responsivo / Mobile-First.
